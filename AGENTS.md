## Visual

Este projeto segue o Padrão BI. Antes de criar ou alterar qualquer página do Power BI, painel web, gráfico, PDF, slide ou capa, leia `marca/REGRAS.md` e `DESIGN.md`.

- Acento deste projeto: `azul`.
- Cores, tipos e medidas vêm só de `marca/tokens.json`. Para gerar temas e estilos: `python marca/gerar.py --acento azul`.
- Nunca edite `marca/tokens.css`, `marca/powerbi/*.json`, `marca/quarto/_brand.yml`, `marca/quarto/typst-template.typ` nem `marca/marca.mplstyle`: são gerados.
- Antes de entregar, siga a lista "Antes de entregar" de `marca/REGRAS.md`.
